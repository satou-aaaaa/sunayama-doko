# どこから砂山？（sunayama-doko）

砂山から少しずつ減らし、そのたびに「砂山・ちがう・分からない」を答えて、自分の境目をさがす学習ゲーム。答えが変わった所の近くでは1粒ずつ減らす。続けて、天気予報の「一時」「時々」や猛暑日のような、はっきり決めた線の問題を1日5問。最後に、自分の線と決めた線をくらべる。言葉のあいまいさ（砂山のパラドックス）を、自分の答えで体験する。

遊ぶ: <https://satou-aaaaa.github.io/sunayama-doko/>

- 砂山には正解がありません。何粒から砂山かは決まっていないからです（Hyde & Raffman「Sorites Paradox」スタンフォード哲学百科事典 <https://plato.stanford.edu/entries/sorites-paradox/> ）。
- 決めた線の問題は、気象庁「予報用語」の時に関する用語（<https://www.jma.go.jp/jma/kishou/know/yougo_hp/toki.html> ）と気温に関する用語（<https://www.jma.go.jp/jma/kishou/know/yougo_hp/kion.html> ）に書いてあることだけです（2026-11-27 に読んだもの）。くらべる線として、民法 第4条の成年18歳（<https://laws.e-gov.go.jp/law/129AC0000000089> ）も出します。
- 説明は予報用語を短く言いかえたものです。公式の情報の代わりではありません。実際の予報や言葉の決まりは、気象庁の発表で確かめてください。
